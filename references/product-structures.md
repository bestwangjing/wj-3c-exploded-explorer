# 产品结构指南

只读匹配当前产品的内容。以下是概念建模方向，不是厂商拆机事实。

| 产品 | 形态与拆解方向 | 重点结构 |
|---|---|---|
| 手机 | 扁平圆角机身，屏幕和背盖沿厚度分离 | 盖板/触控/显示/支撑层，中框/后盖，电池/保护板，主板/子板/芯片，摄像头镜片/传感器，扬声器/振动/接口/天线，胶框和螺丝 |
| 笔记本 | 基座和铰接屏幕，基座沿厚度拆、屏幕沿自身法向拆 | 键帽/键盘底板/触控板，上壳/底盖，屏幕/背板/铰链，主板/处理器/内存/SSD，风扇/热管/鳍片，电池/接口/紧固件 |
| 台式机 | 箱体框架，侧板与前面板沿各自法向分离 | 主板/CPU/内存/插槽，显卡/显存/散热器，CPU 散热/机箱风扇，电源/线束，SSD/硬盘，面板/接口/支架 |
| 运动相机 | 前镜头与显示屏，光路沿镜头轴拆 | 保护镜/镜组/间隔环，传感器/排线，中框/密封，主板/电池，前后屏，散热/屏蔽/接口 |
| 平板 | 大面积薄机身，主要沿厚度展开 | 显示叠层，大电池，主板，扬声器，摄像头，天线；磁吸/手写笔结构仅有依据时加入 |
| 无线耳机与盒 | 左右耳机和盒体为三个子装配体 | 耳机外壳/声学单元/振膜/磁路/声管/麦克风/电路/电芯/触点；盒体铰链/电池/充电板 |
| 机械键盘 | 键位保持矩阵，上下壳竖向展开 | 键帽/轴体/定位板/PCB/稳定器/消音垫/主控/接口/脚撑 |
| 手柄或掌机 | 左右握持壳体，中央主板 | 按钮/导电胶/摇杆/触发器/弹簧/振动/电源/电池；掌机增加屏幕和散热 |
| 无人机 | 机身为中心，机臂和动力向外展开 | 机架/电机/桨/飞控/电调/电池/天线/相机/紧固件；云台按类型选择 |

先设计装配关系，再定拆解位移。键帽、电容、螺丝等真实重复零件可以独立计数；走线、文字、轮廓、像素阵列、风扇叶片等装饰不可凑数。不要给固定孔径运动相机凭空增加可变光圈。没有证据时不要填写真实容量、接口速度、光学曲率或芯片型号。

指定型号时区分外观证据和内部结构证据。优先采用用户给的 CAD 或拆机素材，外观宣传图不能证明内部排列。缺少精确 CAD 时仍完成概念页面，说明精度范围。
