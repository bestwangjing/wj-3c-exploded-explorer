# 验收

首先确认产品轮廓、目录、标题、总览缩略图与输入一致，不残留旧相机内容。

可用环境中已有 Playwright 执行：

```text
node <skill-dir>/scripts/verify-browser.cjs --url http://127.0.0.1:4173 --output <qa-dir> --playwright <absolute-package-path> --browser <installed-chromium-executable>
```

默认模块可解析、浏览器已安装时可省略对应参数。也可用当前环境支持的浏览器工具做等价验证，不假定其他用户存在本机 Edge 路径。

脚本验证真实渲染、唯一 ID、归位、展开、搜索、拾取、隔离、显隐、透视、视角、动画、导出、桌面布局和脚本错误，生成截图及 JSON 报告。

必须查看截图：

- 整机可识别，屏幕/接口/壳体无明显错位。
- 展开主体占中央视区，标签不大量遮挡，控制条不盖关键零件。
- 手机有屏幕和镜头；笔记本有基座与屏幕；台式机有机箱和板卡。
- 不是相同方块凑数；使用不同材料、走线、孔位、触点等。
- 小零件隔离及缩略图显示该零件，而非静态总览图。

只报告实际执行的验证。未核实的工程真实性、未测浏览器、无图形环境或发布失败，与已完成项分别说明。源码生成不等于交互通过。
